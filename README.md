# grunt-test

A simple todo app for adding, completing, filtering, and clearing tasks. Tasks persist across reloads via the browser's `localStorage`.

## Tech

- [React](https://react.dev/) (with TypeScript)
- [Fluent UI](https://react.fluentui.dev/) (`@fluentui/react-components`, `@fluentui/react-icons`) for the interface
- `localStorage` for client-side persistence

## Getting started

Install dependencies:

```
npm install
```

Run the app in development mode:

```
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

Build for production:

```
npm run build
```

The optimized output is written to the `build` folder.
